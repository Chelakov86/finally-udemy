# Domain Documentation

This project uses a single-context layout for domain knowledge.

## Location

- **Main Plan**: `planning/PLAN.md`
- **Market Data Summary**: `planning/MARKET_DATA_SUMMARY.md`
- **ADRs**: Architectural decisions should be recorded in `docs/adr/`.

## Consumer Rules

- Always consult `planning/PLAN.md` for high-level project goals and architectural overview.
- Use `planning/MARKET_DATA_SUMMARY.md` for specific details regarding the market data component.
- When proposing architectural changes, check for existing ADRs in `docs/adr/`.
