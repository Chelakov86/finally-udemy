# GitHub Issue Tracker

Issues for this project are tracked using GitHub Issues.

## Workflow

- **Creation**: Use `gh issue create` to create new issues.
- **Listing**: Use `gh issue list` to view active issues.
- **Reading**: Use `gh issue view <number>` to get issue details.
- **Updating**: Use `gh issue edit` or `gh issue comment` for updates.

## Automation Rules

- When creating implementation tickets from a PRD or spec, use vertical slices (tracer bullets).
- Ensure every issue has a clear "Definition of Done".
- Link issues to relevant milestones or projects if applicable.
