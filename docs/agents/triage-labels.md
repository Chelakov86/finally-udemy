# Triage Labels

The `triage` skill uses the following labels to manage the issue lifecycle.

| Role | Label | Description |
|---|---|---|
| `needs-triage` | `needs-triage` | New issues requiring maintainer evaluation. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous implementation. |
| `ready-for-human` | `ready-for-human` | Requires human intervention or complex decision making. |
| `wontfix` | `wontfix` | Will not be actioned. |
